# QueueManagementSystem-AdminPage
## A Smart Queue Management System for Bank
### METU NCC Computer Engineering Graduation Project
#### About Project:
The main goal of this project is to develop a queue management system that supports 
various priorities, including age, customer types, and dynamic priority, which can be 
adjusted based on the application area. Moreover, thanks to the queue algorithms used in 
the application, although our application is valid for banks, it can be used in all areas where 
queue algorithms should be used in the future. 
1. Priority queue management, where priorities will be managed with different 
factors, including age, customer types, and dynamic priority. 
2. Providing benefits in time management and showing the nearest bank branches in 
the region to help the time management of customers. Moreover, it can help with 
time issues with implementing the dynamic priority feature. 
3. Offering the chance to use time efficiently because of taking queues and following 
queue numbers remotely.
